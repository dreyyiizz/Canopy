║                    CANOPY - PLANT ROOF WEB CONTROL                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

  A localhost web application for controlling your Arduino-powered plant roof
  directly from your laptop browser. No mobile app, no network configuration!

📋 QUICK START

  ┌─ 30-SECOND DEMO (No Hardware) ───────────────────────────────────────────┐
  │                                                                           │
  │  1. Double-click Start-Canopy.cmd                                        │
  │  2. Type DEMO when asked for COM port                                    │
  │  3. Browser opens automatically                                          │
  │  4. Enter the connection key from terminal                               │
  │  5. Try the controls!                                                    │
  │                                                                           │
  └───────────────────────────────────────────────────────────────────────────┘

  ┌─ REAL HARDWARE SETUP (5 Minutes) ────────────────────────────────────────┐
  │                                                                           │
  │  FIRST TIME:                                                             │
  │   1. Install Arduino IDE                                                 │
  │   2. Install libraries: Servo, DHT sensor, Adafruit Unified Sensor       │
  │   3. Upload firmware/CanopyUno/CanopyUno.ino to your Arduino            │
  │                                                                           │
  │  EVERY TIME:                                                             │
  │   1. Connect Arduino via USB                                             │
  │   2. Run Start-Canopy.cmd                                                │
  │   3. Enter your COM port (e.g., COM3)                                    │
  │   4. Browser opens with control interface                                │
  │   5. Enter connection key                                                │
  │   6. Control your roof!                                                  │
  │                                                                           │
  └───────────────────────────────────────────────────────────────────────────┘

🎮 CONTROLS

  Open Roof      → Fully open (level 30)
  Close Roof     → Fully closed (level 0)
  Slider         → Fine adjustment (0, 5, 10, 15, 20, 25, 30)
  Apply Position → Send slider value to Arduino

  Live Readings:
  • Temperature (°C) — Updated every 2 seconds
  • Humidity (%)     — Updated every 2 seconds

  Physical buttons on Arduino work independently!

🔧 REQUIREMENTS

  ✓ Windows laptop (adaptable to Mac/Linux)
  ✓ Python 3.10+ with pip
  ✓ Modern web browser (Chrome, Firefox, Edge)
  ✓ Arduino Uno with USB cable
  ✓ Arduino IDE (for firmware upload)

  Hardware:
  ✓ 2× Servo motors
  ✓ 1× DHT11 temperature/humidity sensor
  ✓ 4× Push buttons (optional)
  ✓ Power supply for servos (don't use USB power!)

❓ TROUBLESHOOTING

  No ports found         → Plug in Arduino (data cable, not charge-only)
  Port is busy           → Close Arduino Serial Monitor
  Arduino offline        → Check COM port, wait 3-5 seconds after connecting
  Server offline         → Make sure Start-Canopy.cmd is running
  Temperature shows —    → Check DHT11 wiring, wait 2 seconds
  Roof wrong direction   → Edit servo constants in Arduino code
  Browser doesn't open   → Manually open http://127.0.0.1:8765
