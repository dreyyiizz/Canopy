Welcome! This is Canopy — a web-based control system for your Arduino-powered
plant roof. Everything runs on your laptop, no mobile app or Wi-Fi needed!

🚀 FASTEST START (30 seconds)

   1. Double-click:  Start-Canopy.cmd
   2. Type:          DEMO
   3. Browser opens automatically
   4. Enter the connection key from terminal
   5. Try the controls!

   This runs in demo mode — safe to experiment, nothing moves.

🎯 WHAT IS CANOPY?

   Canopy controls an Arduino-powered plant roof directly from your web browser:

      ┌─────────────┐          ┌─────────────┐          ┌──────────────┐
      │   Browser   │  ◄───►   │   Python    │  ◄───►   │  Arduino Uno │
      │  (You!)     │  HTTP    │   Server    │   USB    │   + Servos   │
      └─────────────┘          └─────────────┘          └──────────────┘
                                                                │
      All on your laptop                                       ▼
      No Wi-Fi needed!                                   ┌──────────────┐
                                                         │  Plant Roof  │
                                                         │  Opens/Closes│
                                                         └──────────────┘

   Features:
   ✓ Open/close roof with buttons or slider
   ✓ Live temperature & humidity readings
   ✓ Animated visualization
   ✓ Physical buttons still work
   ✓ Demo mode for safe testing
   ✓ Automatic browser launch

🛠️  WHAT YOU NEED

   Software:
   ✓ Python 3.10+ (install from python.org)
   ✓ Arduino IDE (for uploading firmware)
   ✓ Modern web browser (Chrome, Edge, Firefox)

   Hardware:
   ✓ Arduino Uno with USB cable
   ✓ 2× Servo motors
   ✓ 1× DHT11 temperature/humidity sensor
   ✓ 4× Push buttons (optional)
   ✓ Power supply for servos (5-6V, 2A+)

❓ COMMON QUESTIONS

   Q: Do I need a mobile phone?
   A: No! Everything runs in your laptop's web browser.

   Q: Do I need Wi-Fi?
   A: No! Everything runs on localhost (127.0.0.1).

   Q: Can I control it remotely?
   A: This version is laptop-only. For remote control, see CHANGELOG.md
      for information about the original mobile app version.

   Q: What if I don't have an Arduino yet?
   A: Try demo mode! Just type DEMO when prompted for the COM port.

   Q: Where's the connection key?
   A: It's shown in the terminal window when you run Start-Canopy.cmd

   Q: Can I change the key?
   A: Delete bridge/.canopy-key and restart. A new key generates.

   Q: The browser didn't open automatically?
   A: Just open any browser and go to: http://127.0.0.1:8765

   Q: Temperature shows dashes?
   A: Check DHT11 wiring to pin D2. Wait 2 seconds for first reading.

   Q: Servos don't move?
   A: Use external power supply (NOT Arduino 5V). Check wiring.
